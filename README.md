# 弹壳地牢

一个零依赖、无需安装开发环境的俯视角肉鸽地牢射击小游戏。玩法参考《以撒的结合》的房间推进、单局成长和弹幕战斗结构；视觉与素材均由 Canvas 原创绘制，不包含原作资源。

## 在线试玩

- EdgeOne Makers 第二版：<https://mcp.edgeone.site/share/7cf02gbUNFc6L4Vu3Axtr>
- 发布版本为单文件静态镜像，内联了项目中的 `style.css` 与 `game.js`，无需下载或安装即可游玩。
- 已在公网版本验证桌面键鼠、移动端触控释放、农场锻造、商店购买、遗物图鉴、11 个 Boss 状态机和终局路线，浏览器控制台错误为 0。

## 启动

直接双击 `index.html`，浏览器会打开游戏。

如果浏览器限制本地文件，也可以使用任意静态文件服务；这不是运行游戏的必要条件。推荐使用 Chrome、Edge、Safari 或 Codex 内置浏览器。

## 操作

- `WASD`：移动
- 鼠标左键或方向键：射击
- 鼠标右键按住：向光标位置移动（键盘输入被浏览器拦截时也可使用）
- `空格`：无敌翻滚
- `Q`：释放所选英雄的主动技能
- `I`：打开遗物图鉴与当前构筑说明（图鉴打开时自动暂停）
- 手机：建议横屏游玩；开始游戏时会尝试进入横屏全屏，也可随时点击顶部“横屏全屏”；左侧摇杆移动，右侧按钮射击、技能和翻滚

所有普通遗物都会在触碰或购买后**自动生效**，不需要额外按键。标记为“武器核心”的遗物会自动切换或升级攻击方式；只有英雄技能需要按 `Q` 主动释放。

## 内容

### 第二版重点升级

- 四名英雄重做为爆破护甲、赌徒礼帽与单片镜、秘仪兜帽与第三眼、囚笼头盔与重肩甲四套完整剪影，持有的七种武器均有独立模型
- 八类普通敌人强化职责轮廓：炮台三脚底座、冲锋甲壳、召唤法袍、炸弹背包等结构在远距离也能快速辨认
- 11 个 Boss 的基础生命提升至 `124–520`，叠加楼层成长、三段锁血和阶段转换，避免成型构筑直接秒杀
- 每个 Boss 拥有独立招牌招式与预警：断节毒轮、多重天坠、暴食吸积、育巢螺旋、双瞳十字、母影夹击、空骨回返、狂搏血墙、裂眼三光、连环掘袭、双蹄审判
- 每个 Boss 使用独立弹体颜色、拖尾和轮廓，包括毒刺、脓滴、獠牙、孢卵、泪滴、血掌、骨片、心形血珠、眼球、圣髓碎片和狱火
- 二、三阶段不再只换数值：会长出毒囊、强化腿部、张开巨颚、环绕孢卵、脱落眼球、召出巨掌、生成残影、扩张血管、裂出双眼、增生背甲或展开双蹄
- 三阶段伤害倍率从旧版 `1.75` 收敛到 `1.42`，保留 1 秒受击无敌；强招统一提供约 `0.5–0.9` 秒预警，并留下可持续输出的安全窗口
- 七种武器补充持续轨迹和独立命中特效，游魂弹与霰火弹新增专属弹体造型，暴击、棱镜折射、回旋收刀的视觉层级更清晰

- 完整战役包含 11 个下坠深度、每层 5 个房间，共 55 个房间与 11 场 Boss 战
- 前四章各有 I、II 两层，并从地窖、洞穴、深层和血肉四组替代环境中生成；之后进入苍蓝裂隙，并在圣堂/魔窟与遗箱/深室之间选择终局路线
- 每层包含普通战斗、三选一宝库、商店、精英房和章节 Boss，具体敌人组合与房间词缀随机生成
- 战场扩展为 `1280×720` 的 16:9 大房间，可见地板网格由约 14×8 增加到 18×11，角色与普通敌人在视野中的占比同步缩小
- 爆破者、铸币客、秘仪师、囚笼巨人 4 名英雄，拥有不同初始属性、外观和主动技能
- 农场与锻造闭环：普通敌人和精英会掉落种子，Boss 固定带回种子与阶段图纸；种植约 20 秒后收获骨粉、幽晶和血藤汁
- 追击射手、三连发炮台、蓄力冲撞者、蝙蝠突袭者、分裂怪、吸血虫、邪教徒和炸弹客，共 8 类普通敌人
- 11 个三阶段 Boss 分别使用轴向蛇行、跳跃落地、对齐冲锋、固定炮台、脱眼压场、门边攻击、对角反弹、节拍弹幕、三向光束、潜地弱点和连续踩踏机制
- Boss 高危动作统一提供落点圈、冲锋线或光束轨迹前摇；潜地 Boss 只在尾部暴露窗口可受伤
- Boss 生命与成长曲线重新平衡，三阶段之间加入锁血变身；超额伤害不能越阶段秒杀，二、三阶段会扩大体型并显著提高移速、攻频、弹速、弹体和伤害
- 追击、远程、冲锋、护持、召唤、地形控制职责会组合出现；敌人之间会相互避让，减少不可读的重叠
- 精英随机获得护盾、狂怒、汲血、爆裂 4 种词缀，并使用独立色环、名称和反馈
- 36 种可重复拾取的遗物，组成摧毁、硬币、咒文、泰坦四条流派；每条流派拥有三件套和五件套质变
- 遗物图鉴展示全部道具的类别、使用方式、效果、解锁要求和本局叠加层数；商店与宝库在拾取前同时显示完整效果
- 摧毁流可拆解陶罐永久成长，硬币流按持币量增伤，咒文流触发连锁伤害，泰坦流强化生命、减伤和狂暴
- 连弩、霰火、游魂、祭刃 4 种基础武器；工坊可制作持续锁敌的追魂蜂巢、命中折射的星陨棱镜和飞出回收的血月环刃
- 燃烧、冻结、中毒、流血、感电 5 种状态，以及冻结碎裂、燃烧爆炸、流血近战吸血等规则联动
- 宝库每次展示 3 件遗物并严格三选一；商店货架固定不受磁力吸附，支持靠近或点击购买，并清晰显示价格与持有金币
- 每章宝库后选择守烛圣所或双誓险路，在恢复续航与强化精英双倍奖励之间取舍
- 岩石、陶罐、尖刺组成可碰撞战场；陶罐可击碎掉落货币，炸弹可破坏场景
- 虫潮、狂热、富矿、诅咒 4 种随机房间词缀改变敌人数量、速度、掉落和风险收益
- 连杀计时、无伤清房奖励、技能冷却、精英强化和章节递进共同组成战斗节奏
- 移动采用加速、转向和刹停速度模型；身体朝移动方向、头部与武器独立瞄准，翻滚包含压缩和残影
- 攻击包含后坐、枪口火光、弹道拖尾、命中停顿、定向火花、伤害数字和暴击差异反馈
- 生命、弹壳币、掉落物、属性面板、双排道具栏、当前楼层地图与 11 层下坠进度
- 开始、死亡、通关完整流程，结算伤害构成、承伤、死因、击杀、遗物、存活时间和房间进度
- `localStorage` 保存远征、通关、Boss 印记和最佳击杀，并逐步解锁初始武器与高阶遗物
- 自适应桌面与手机屏幕，移动端支持自动请求横屏全屏并保留手动入口
- 手机横屏以完整 16:9 比例铺满可用高度；竖屏仍保留完整横向视野并显示旋转提示
- Web Audio 原生合成射击、翻滚、受击、拾取、技能和击杀反馈，不依赖外部音频文件

## 技术选型

技术栈仅使用 HTML5 Canvas、CSS 与原生 JavaScript。选择原生 Canvas 是为了让成品可通过 `file://` 直接运行，不依赖 Node.js、构建工具、第三方库或联网资源。

开发时核对了 [MDN CanvasRenderingContext2D](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D) 与 [MDN Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events) 的当前接口说明，用于高分屏缩放、路径绘制、渐变、指针捕获和真实触控处理。

## 原创视觉系统

- 角色、普通敌人、Boss、道具图标和场景摆件全部使用 Canvas 程序化绘制
- 采用不规则轮廓、粗描边、手绘形变、皮肤斑点、缝线、甲片、翼膜与动态肢体，形成统一的暗黑卡通质感
- 六套环境色板覆盖地窖、洞穴、墓城、血肉、圣堂与魔窟；包含地板、墙体、火炬、污渍、裂缝、碎骨、灰烬、蜡烛与血肉组织装饰
- 玩家装备会改变外观；护盾、光环、火药等道具拥有可见反馈
- 包含动态火炬光晕、玩家附近照明、远景暗角、落地阴影、受击闪白、击退、命中停顿和方向性粒子反馈
- Boss 使用更大的原创轮廓、独立材质与仪式法阵，和普通敌人保持清晰层级
- Boss 二阶段追加个体器官变异、青色符文与专属组合攻击；三阶段体型膨胀、骨刺裂纹、粉红狂怒光环和独立终结招式

## 调试接口

浏览器控制台可使用 `window.__game`：

- `window.__game.getState()`：查看生命、玩家坐标/速度、敌人状态、弹量、Boss 阶段、路线、局外进度与伤害统计
- `window.__game.start()`：开始新的一局
- `window.__game.clearRoom()`：测试用，立即清除当前房间敌人
- `window.__game.collectPickups()`：测试用，将掉落物移到玩家脚下
- `window.__game.exitRoom()`：测试用，在门开启后进入下一房间
- `window.__game.goToRoom(49)`：测试用，跳转到指定房间
- `window.__game.damageBoss(9999, true)`：测试用，验证 Boss 单次伤害上限与阶段锁血
- `window.__game.triggerBossSignature()`：测试用，立即触发当前 Boss 的独立招牌招式和预警
- `window.__game.chooseRoute("risk")`：测试用，选择高风险路线
- `window.__game.chooseRoute("sheol")`：测试用，在终局分岔选择魔窟路线
- `window.__game.giveItem("powder")`：测试用，授予指定道具并验证叠加
- `window.__game.hurt()`：测试用，对玩家造成伤害
- `window.__game.selectHero("seer")`：测试用，选择英雄
- `window.__game.useSkill()`：测试用，释放当前英雄技能
- `window.__game.toggleGuide(true)`：测试用，打开遗物图鉴
- `window.__game.toggleWorkshop(true)`：测试用，打开农场与锻造工坊
- `window.__game.equipWeapon("seeker")`：测试用，立即装备追踪、折射或回旋武器

## 已知不足

- 每层采用线性五房间压缩结构，尚未实现可自由回溯的二维房间地图
- 为保持本地直接运行与版权独立性，不包含外部美术和音乐资源；音效由浏览器实时合成
